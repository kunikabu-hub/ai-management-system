# 記事・下書き

このディレクトリには、`/write-draft` スキルで生成された記事の下書きが保存されます。

---

## 📁 ファイル命名規則

```
YYYY-MM-DD_[テーマ（短縮）].md
```

**例**:
- `2026-02-12_パーソナライズ絵本の魅力.md`
- `2026-02-12_AI時代の子育て.md`
- `2026-02-12_顧客ロイヤリティと絵本.md`

---

## 📝 記事の種類

### B2C記事
- **ターゲット**: 子育て世代、祖父母、新婚カップル、ペットオーナー
- **トーン**: 親しみやすい、やわらかい
- **目的**: サービス認知、リード獲得、購入促進

**テーマ例**:
- 絵本のパーソナライズについて
- 子どもの成長と絵本の役割
- AI時代の子育て
- ペット絵本の魅力

### B2B記事
- **ターゲット**: 企業の経営者、マーケティング担当者、営業担当者
- **トーン**: プロフェッショナル、データ重視
- **目的**: リード獲得、事例紹介、サービス理解促進

**テーマ例**:
- 顧客ロイヤリティを高める絵本活用法
- 企業ギフトとしての絵本の可能性
- 感情データの物語化とは

### 技術・トレンド記事
- **ターゲット**: 技術者、事業開発担当者、一般読者
- **トーン**: 中立的、客観的
- **目的**: 専門知識の提供、トレンド紹介、思考リーダーシップ

**テーマ例**:
- AI画像生成技術の進化と絵本制作
- パーソナライズギフト市場のトレンド
- 生成AIと絵本の未来

## 📊 記事の構成

各記事には以下の要素が含まれます：

### 必須要素
1. **タイトル候補**（3パターン）
   - 真面目・正統派
   - キャッチー
   - SEO重視

2. **メタ情報**
   - 作成日
   - テーマ
   - ターゲット読者
   - 文字数

3. **導入**（200-300文字）
   - 読者の興味を引く
   - 記事の内容を簡潔に紹介

4. **本文**（3-5セクション、各500-800文字）
   - 見出し付き
   - データ・事例を含む
   - 読者にとっての価値を明確に

5. **まとめ**（200-300文字）
   - 要点をまとめる
   - CTA（Call To Action）

6. **参考資料**
   - Google Drive資料
   - 05_learning/情報
   - トレンド分析
   - 記憶（00_context/memories/）
   - Web情報源

### オプション要素
- SEOキーワード
- 推奨公開媒体
- 推奨公開日
- 関連記事へのリンク

## 🎯 使い方

### 新しい記事を生成

```bash
# テーマを指定して実行
/write-draft 絵本のパーソナライズについて

# B2B向け記事
/write-draft 顧客ロイヤリティを高める絵本活用法

# 技術・トレンド記事
/write-draft AI画像生成技術の進化と絵本制作
```

### 記事の確認・編集

```bash
# 最新の記事を表示
ls -lt output/articles/

# 特定の記事を開く
cat output/articles/2026-02-12_パーソナライズ絵本の魅力.md
```

### 公開前のチェックリスト

- [ ] タイトルが魅力的で、テーマを正確に表現しているか
- [ ] 導入で読者の興味を引いているか
- [ ] 本文が読者にとって価値ある情報を提供しているか
- [ ] データ・事例が適切に引用されているか
- [ ] まとめが要点を的確にまとめているか
- [ ] CTAが明確で、行動を促しているか
- [ ] 参考資料が適切に記載されているか
- [ ] 文体・トーンが一貫しているか
- [ ] 誤字脱字がないか
- [ ] SEOキーワードが適切に含まれているか

## 📁 記事の整理

定期的に記事を整理することを推奨します：

### 1ヶ月以上前の記事
- 公開済みの記事は、アーカイブディレクトリに移動
- または削除（Gitで履歴は残る）

### 公開した記事
- 公開日、公開媒体、URLをメタ情報に追記
- アクセス数、反応をメモ

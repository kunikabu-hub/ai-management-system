# トレンド分析レポート

このディレクトリには、`/trend-check` スキルで生成されたトレンド分析レポートが保存されます。

---

## 📁 ファイル命名規則

```
YYYY-MM-DD_[キーワード]_trends.md
```

**例**:
- `2026-02-12_default_trends.md` - デフォルト検索（キーワード指定なし）
- `2026-02-12_絵本_trends.md` - 「絵本」キーワード検索
- `2026-02-12_AI_trends.md` - 「AI」キーワード検索

---

## 📊 レポートの内容

各レポートには以下の情報が含まれます：

### 1. エグゼクティブサマリー
- 主要なトレンド（トップ5）
- えほんインクへの影響（機会・リスク）
- 推奨アクション

### 2. カテゴリ別トレンド
- 業界動向
- 技術トレンド
- 競合分析
- 顧客インサイト
- マーケティング
- ビジネスモデル
- 規制・法律
- その他

### 3. 詳細情報
- 検索クエリ一覧
- 情報源一覧
- メモ・気づき
- 関連リンク

---

## 🔄 推奨更新頻度

- **デフォルト検索**: 週1回（毎週月曜日推奨）
- **特定キーワード**: 月1回
- **緊急時**: 必要に応じて随時実行

---

## 🎯 使い方

### 新しいレポートを生成

```bash
# デフォルト検索
/trend-check

# 特定キーワード検索
/trend-check 絵本
/trend-check AI
/trend-check AI 絵本
```

### レポートの確認

```bash
# 最新のレポートを表示
ls -lt output/trends/

# 特定のレポートを開く
cat output/trends/2026-02-12_default_trends.md
```

### 重要な情報を保存

レポートから重要な情報を見つけたら、`/agent-memory` で長期記憶に保存：

```bash
/agent-memory
```

---

## 📝 レポートの整理

定期的に古いレポートを整理することを推奨します：

### 1ヶ月以上前のレポート
- アーカイブディレクトリに移動
- または削除

### 重要な情報
- `/agent-memory` で `00_context/memories/market_insights.md` に保存
- レポートは削除してOK

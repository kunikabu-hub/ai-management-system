## エグゼクティブサマリー

### 現状評価

えほんインクは、AIパーソナライズ絵本市場において独自のポジションを確立しつつある成長期企業です。B2C（4,500円〜/冊）とB2B（成約特典モデル、代理店販売15%還元、AIナラティブDB）の両輪戦略により、安定した収益基盤を構築しています。

**市場環境**:
- パーソナライズ絵本市場は少子化にもかかわらず成長継続
- 主要競合: STUDIO BUKI（BabyTech Award 2021大賞、JALコラボ）、Wonderbly（英国発）
- AI生成コンテンツ市場は年平均成長率23.4%で拡大中
- フォトウェディング市場869億円（2023年）、実施率70.6%と高需要

**強み**:
- 3Dアバター生成技術（50万通りの組み合わせ）
- 感情データの物語化（ナラティブDB）による差別化
- B2B大手との実績（ガリバー、旭化成ホームズ、鈴木自工2026/4/1導入開始）

**課題**:
- ユーザー離脱率の高さ（カスタマイズの手間）
- 継続利用モデルの未確立（LTV低下リスク）
- 代理店網の構築途上（ナック交渉中）

### 主要な発見

1. **市場機会**: 「超パーソナライズ」が2026年のAIトレンドキーワードとして注目され、えほんインクのコアコンセプトと合致
2. **競合優位性**: STUDIO BUKIは高品質路線、えほんインクは3Dアバター＋感情データ活用で差別化可能
3. **収益性**: AI生成コスト400円/冊、販売価格4,500円で粗利率91%と高収益構造
4. **B2B成長性**: 法人ギフト市場で「6.5人に1人がパーソナライズギフト利用経験」、約6割が利用意向
5. **技術的優位**: カスタマイズ絵本で月180万円稼ぐ海外事例あり、ビジネスモデルの実証済み

### 重要な推奨事項

**即座に実行すべき施策（2026年2-4月）**:
1. **鈴木自工導入の成功事例化**（2026/4/1〜）: 納車式での感動体験をSNS拡散、導入後3ヶ月でROI測定

3. **ユーザー離脱防止の緊急対策**: カスタマイズを3ステップ以内に簡素化、プレビュー機能の限定導入
4. **ペット絵本MVP開発**: LINEボット活用で日常的なインプットを実現、3月末リリース目標

**中期戦略（2026年2-7月）**:
- サブスクリプションモデル導入（月額2,980円で季節ごとの絵本配送）
- AIナラティブDBのかんぽ生命実証実験開始

**長期ビジョン（2026年通年）**:

## 6. データサイエンティスト視点

### AIナラティブDB戦略

#### ナラティブDBの概念

**定義**:
- 顧客・社員の「感情」「物語」をAIで構造化・データベース化
- 単なるCRM（顧客関係管理）ではなく、NRM（Narrative Relationship Management）

**構成要素**:
1. **感情データ**: 喜び、不安、期待、愛情など
2. **ライフイベント**: 誕生、結婚、出産、転職、終活など
3. **関係性データ**: 家族、友人、ペット、商品との関係
4. **物語パターン**: 成功、挑戦、成長、別れ、再会など

**価値提案**:
- 既存CRMでは捉えきれない「感情」要素を可視化
- 顧客インサイトの深化→パーソナライズ施策の精度向上
- 営業・マーケティングツールとしての活用
- 新規サービス開発のネタ

#### ナラティブDB構築プロセス

**Step 1: データ収集**

*データソース*:
- アンケート: 感情、ライフイベント、願望
- SNS: 投稿内容、写真、ハッシュタグ
- カスタマーサポート: 問い合わせ内容、トーン
- 購買履歴: 購入タイミング、頻度、商品
- センサーデータ: ウェアラブル、スマートホーム（将来）

*えほんインクの場合*:
- カスタマイズ時の設問回答（使用目的、移動先、同乗者など）
- 写真データ（表情、シーン、背景）
- LINEボット投稿（日常的なエピソード、感情）
- レビュー・SNS投稿（感想、感動の瞬間）

**Step 2: AI分析・構造化**

*自然言語処理（NLP）*:
- 感情分析: テキストから喜び、不安、期待などを抽出
- トピックモデリング: 主要テーマの自動抽出
- エンティティ抽出: 人物、場所、イベントの識別

*画像認識*:
- 表情認識: 笑顔、驚き、悲しみなどの感情
- シーン認識: 家族、ペット、車、家などのコンテキスト
- オブジェクト検出: 具体的なアイテム

*物語生成AI*:
- GPT-4等のLLMを活用
- 感情データ + ライフイベントを物語化
- パーソナライズされたストーリー自動生成

**Step 3: データベース化**

*データ構造*:
```
顧客ID: 12345
├─ 基本情報（年齢、性別、家族構成）
├─ 感情プロファイル
│   ├─ 主要感情: 喜び（70%）、期待（20%）、不安（10%）
│   └─ 感情推移: 時系列データ
├─ ライフイベント
│   ├─ 過去: 結婚（2020年）、出産（2022年）
│   └─ 未来: 車購入（検討中）、マイホーム（2027年予定）
├─ 関係性
│   ├─ 家族: 配偶者、子供（3歳）
│   ├─ ペット: 犬（ゴールデンレトリバー、5歳）
│   └─ 商品: 車（トヨタ、2018年購入）
└─ 物語パターン
    ├─ 「家族の成長」: 子供の誕生→育児の喜び→車購入検討
    └─ 「ペットとの冒険」: 犬を飼う→週末ドライブ→思い出づくり
```

**Step 4: 活用**

*B2C活用*:
- パーソナライズ絵本の自動生成
- レコメンデーション（次に欲しい絵本）
- マーケティング施策の最適化

*B2B活用*:
- 営業ツール（顧客の感情・物語を可視化）
- 顧客インサイトレポート
- 新規サービス開発のネタ

# write-draft

テーマを受け取り、関連資料を参照しながら記事の下書きを生成します。

## 実行内容

このコマンドは、以下のステップで記事の下書きを作成します：

1. **テーマを受け取る**
2. **Google Driveから関連資料を検索・参照**
3. **05_learning/ から関連するインプット情報を確認**
4. **記事の構成案を作成（見出し・流れ）**
5. **各セクションの下書きを生成**
6. **output/articles/ 配下に日付付きファイルで保存**
7. **作成した記事のパスを報告**

---

## 使い方

### 基本的な使い方

```bash
# テーマを指定して実行
/write-draft 絵本のパーソナライズについて

# 複数の単語を含むテーマ
/write-draft AI時代の子育て

# 企業ブログ向けの記事
/write-draft えほんインクのサービス紹介
```

### パラメータ

- **[テーマ]** (必須): 記事のテーマ
  - 具体的なトピック（例: 「絵本のパーソナライズについて」）
  - 幅広いテーマ（例: 「AI時代の子育て」）
  - サービス紹介（例: 「えほんインクのサービス紹介」）

## ステップ2: Google Driveから関連資料を検索・参照

Google Drive内のファイルから、テーマに関連する資料を検索します。

### 検索の実行

**実行内容**:
1. `output/google_drive_files.json` から、テーマに関連するキーワードでファイルを検索
2. 関連性の高いファイルを特定（上位5件程度）
3. 必要に応じて、Google Drive APIを使用してファイルの内容を取得

**検索キーワードの生成**:
テーマから主要なキーワードを抽出し、以下のパターンで検索：
- テーマのメインキーワード（例: 「絵本」「パーソナライズ」）
- 関連キーワード（例: 「子育て」「顧客」「AI」）
- えほんインクの事業領域キーワード（例: 「B2B」「B2C」「ナラティブDB」）

**検索結果の処理**:
```bash
# google_drive_files.json から関連ファイルを検索
cat output/google_drive_files.json | python3 -c "
import sys, json
theme = 'パーソナライズ'  # テーマから抽出したキーワード
files = json.load(sys.stdin)
related = [f for f in files if theme in f['name']]
for f in related[:5]:
    print(f'{f[\"name\"]} - {f[\"id\"]}')
"
```

### 期待する出力例

```
関連資料（Google Drive）:
1. パーソナライズ絵本市場調査_2025.pptx
2. えほんインク_サービス紹介_v3.pdf
3. 鈴木自工_提案資料_20260201.pptx
4. かんぽ生命_ナラティブDB提案.pdf
5. ペット絵本企画書_v2.docx
```

## ステップ3: 05_learning/ から関連するインプット情報を確認

`05_learning/` ディレクトリから、テーマに関連する学習情報を確認します。

### ディレクトリ構造の確認

**実行内容**:
1. `05_learning/` ディレクトリ内のMarkdownファイルを全て検索
2. テーマに関連するキーワードでGrep検索
3. 関連性の高い情報を抽出

**検索の実行**:
```bash
# 05_learning/ から関連情報を検索
grep -r "パーソナライズ" 05_learning/ --include="*.md"
```

### 期待する出力例

```
関連情報（05_learning/）:
- 05_learning/market_trends/personalized_gifts.md
  - パーソナライズギフト市場のトレンド
- 05_learning/best_practices/customer_engagement.md
  - 顧客エンゲージメントのベストプラクティス
```

**注意事項**:
- `05_learning/` が空の場合は、スキップ
- 関連情報がない場合は、一般的な知識と `00_context/memories/` の情報を活用

## ステップ4: 記事の構成案を作成（見出し・流れ）

収集した情報を基に、記事の構成案を作成します。

### 構成案のフォーマット

```markdown
# 記事構成案

## タイトル候補（3パターン）

1. [メインタイトル] - [サブタイトル]
2. [キャッチーなタイトル]
3. [SEO重視のタイトル]

## ターゲット読者

- [ターゲット1]
- [ターゲット2]

## 記事の目的

- [目的1]
- [目的2]

## 記事の流れ

### 導入（200-300文字）
- [導入の要点1]
- [導入の要点2]

### 本文

#### 見出し1: [見出しテキスト]
- [内容の要点]
- [データ・事例]

#### 見出し2: [見出しテキスト]
- [内容の要点]
- [データ・事例]

#### 見出し3: [見出しテキスト]
- [内容の要点]
- [データ・事例]

### まとめ（200-300文字）
- [まとめの要点1]
- [まとめの要点2]
- [CTA（Call To Action）]

## 参考資料
- [資料1]
- [資料2]
```

### 構成案の作成原則

1. **タイトルは3パターン**:
   - パターン1: 真面目・正統派（例: 「絵本のパーソナライズがもたらす子育ての変化」）
   - パターン2: キャッチー（例: 「世界に1冊だけ！子どもが主人公になる絵本の魔法」）
   - パターン3: SEO重視（例: 「パーソナライズ絵本とは？メリット・選び方を徹底解説」）

2. **ターゲット読者を明確に**:
   - B2C記事: 子育て世代、祖父母、新婚カップル、ペットオーナーなど
   - B2B記事: 企業の経営者、マーケティング担当者、営業担当者など

3. **記事の目的を明確に**:
   - 情報提供、認知度向上、リード獲得、サービス紹介など

4. **本文は3-5セクション**:
   - 各セクションは500-800文字程度
   - データ・事例を含める
   - 読者にとっての価値を明確に

5. **まとめにCTAを含める**:
   - B2C記事: 「無料体験」「資料請求」「商品ページへ」
   - B2B記事: 「お問い合わせ」「事例資料ダウンロード」「無料相談」

## ステップ5: 各セクションの下書きを生成

構成案に基づき、各セクションの下書きを生成します。

### 下書きの生成原則

#### 導入（200-300文字）
- **目的**: 読者の興味を引き、記事を読み進めたくなるようにする
- **構成**:
  1. 読者の課題・疑問を提示（例: 「子どもが絵本に興味を示さない...」）
  2. 解決策のヒントを示唆（例: 「子どもが主人公になる絵本なら？」）
  3. 記事の内容を簡潔に紹介

**良い導入の例**:
```
「うちの子、絵本に全然興味を示さないんです...」

そんな悩みを持つ親御さんは少なくありません。しかし、もし子ども自身が絵本の主人公になれたら、どうでしょうか？自分の名前が出てくる、自分の姿が描かれている絵本なら、きっと夢中になるはずです。

本記事では、「パーソナライズ絵本」がもたらす子育ての変化と、その魅力について詳しくご紹介します。
```

#### 本文（各セクション500-800文字）
- **目的**: 読者に価値ある情報を提供する
- **構成**:
  1. 見出しで内容を明確に示す
  2. 問題提起 or 状況説明
  3. 解決策 or 情報提供
  4. データ・事例で裏付け
  5. 読者にとってのメリットを明確に

**良い本文の例**:
```
## パーソナライズ絵本とは？

パーソナライズ絵本とは、子どもの名前や顔、家族の情報などを反映させた、世界に1冊だけの絵本です。従来の絵本とは異なり、読者（子ども）自身が物語の主人公として登場するため、より深く物語に没入できるのが特徴です。

近年、AI技術の進化により、写真から子どもの顔を忠実に再現したイラストを生成できるようになり、パーソナライズ絵本市場は急成長しています。市場調査会社SDKI Inc.によると、世界のパーソナライズ絵本市場は2025年の約6億ドルから、2033年には11億ドルに達すると予測されています（年平均成長率10%）。

【子どもの反応が変わる理由】
パーソナライズ絵本が子どもの反応を変える理由は、心理学的な観点からも説明できます。子どもは「自分」に関連する情報に強い興味を示す傾向があり、自分の名前や姿が出てくる絵本は、通常の絵本よりも注意を引きつけやすいのです。

実際に、えほんインクを利用した親御さんからは「今まで絵本を読まなかった子が、自分の絵本だけは何度も読んでと言ってくる」という声が多数寄せられています。
```

#### まとめ（200-300文字）
- **目的**: 記事の要点を振り返り、読者に行動を促す
- **構成**:
  1. 記事の要点を簡潔にまとめる
  2. 読者にとってのメリットを再確認
  3. CTA（Call To Action）で具体的な行動を促す

**良いまとめの例**:
```
## まとめ

パーソナライズ絵本は、子どもが主人公になることで、絵本への興味を大きく引き出すことができます。読み聞かせの時間がより楽しく、親子のコミュニケーションも深まります。

AI技術の進化により、高品質なパーソナライズ絵本が手軽に作れるようになった今、お子さんやお孫さんへの特別なギフトとして、ぜひパーソナライズ絵本を検討してみてはいかがでしょうか。

**えほんインクでは、写真から作るアバター絵本を4,500円〜でご提供しています。まずは無料のサンプルページをご覧ください。**

→ [えほんインクのサービスを見る](#)
```

### 文体・トーンのガイドライン

**B2C記事**:
- 親しみやすい、やわらかいトーン
- 「です・ます」調
- 親御さんの目線、共感を大切に
- 専門用語は避けて、わかりやすく

**B2B記事**:
- プロフェッショナルなトーン
- 「です・ます」調
- データ・ROIを重視
- 具体的な事例・数字を含める

**技術・トレンド記事**:
- 中立的、客観的なトーン
- 「です・ます」調 or 「である」調
- データ・統計を重視
- 専門用語は適切に使用（解説付き）

## 実装の詳細

### Google Drive検索の実行

**使用するツール**: Bashツール、Read/Grepツール

**検索の実行順序**:
1. `output/google_drive_files.json` を読み込み
2. テーマから主要なキーワードを抽出
3. ファイル名にキーワードが含まれるファイルを検索
4. 関連性の高いファイルを特定（上位5件程度）
5. 必要に応じて、ファイルの内容を確認（スライドはエクスポート済みのものを参照）

### 05_learning/検索の実行

**使用するツール**: Glob、Grep、Readツール

**検索の実行順序**:
1. `05_learning/` ディレクトリ内のMarkdownファイルを検索
2. テーマに関連するキーワードでGrep検索
3. 関連性の高い情報を抽出
4. 情報を構造化して記事作成に活用

### 記事生成のロジック

**生成の流れ**:
1. テーマと関連資料を分析
2. ターゲット読者を特定
3. 記事の目的を明確化
4. 構成案を作成（タイトル、見出し、流れ）
5. 各セクションの下書きを生成
   - 導入: 読者の興味を引く
   - 本文: 価値ある情報を提供
   - まとめ: 要点をまとめ、CTAで行動を促す
6. 参考資料リンクを追加
7. メタ情報（SEOキーワード、推奨公開媒体など）を追加

   - 画像は著作権フリーのものを使用（生成する場合は別途作成）

2. **情報の正確性**:
   - データ・統計は最新のものを使用
   - 不確実な情報は記載しない
   - 必要に応じて、ユーザーに確認を求める

3. **トーン・文体の一貫性**:
   - ターゲット読者に合わせたトーンを維持
   - 専門用語は適切に解説
   - 文体は統一（です・ます調 or である調）

4. **SEO対策**:
   - タイトルにキーワードを含める
   - 見出しにもキーワードを含める
   - メタディスクリプション（要約）を作成

5. **文字数**:
   - ブログ記事: 2,000〜3,000文字程度
   - note記事: 1,500〜2,500文字程度
   - SNS投稿用要約: 200〜400文字程度

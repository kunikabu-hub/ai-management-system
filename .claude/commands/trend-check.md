# trend-check

Web検索を使って最新のトレンド情報を収集し、分析・保存します。

## 実行内容

このコマンドは、以下のステップで最新のトレンド情報を収集・分析します：

1. **Web検索で最新トレンド情報を収集**
2. **収集した情報をカテゴリ別に分類**
3. **重要度・関連性でランク付け**
4. **output/trends/ 配下に日付付きファイルで保存**
5. **サマリーをユーザーに報告**

---

## 使い方

### 基本的な使い方

```bash
# キーワードなしで実行（デフォルト検索）
/trend-check

# 特定のキーワードで検索
/trend-check 絵本

# 複数のキーワードで検索
/trend-check AI 絵本

# 技術トレンドを検索
/trend-check AI技術
```

### パラメータ

- **[キーワード]** (オプション): 検索するキーワード
  - 指定しない場合は、デフォルトの検索を実行
  - 複数のキーワードを指定可能（スペース区切り）

---

## ステップ1: Web検索で最新トレンド情報を収集

Web検索を使って、以下のカテゴリの最新トレンド情報を収集します。

### デフォルト検索クエリ（キーワード指定なしの場合）

1. **業界ニュース（絵本・出版業界）**:
   - 「絵本 トレンド 2026」
   - 「出版業界 ニュース 2026」
   - 「パーソナライズ絵本 市場動向」
   - 「デジタル絵本 トレンド」

2. **AI/技術トレンド**:
   - 「生成AI トレンド 2026」
   - 「AI 画像生成 最新技術」
   - 「ChatGPT 活用事例 2026」
   - 「AIパーソナライゼーション」

3. **マーケティング・ビジネストレンド**:
   - 「B2B マーケティング トレンド 2026」
   - 「顧客ロイヤリティ 施策 2026」
   - 「サブスクリプション ビジネスモデル」
   - 「D2C トレンド 2026」

4. **競合・類似サービス**:
   - 「パーソナライズギフト 市場」
   - 「AI絵本 サービス」
   - 「カスタマイズ商品 トレンド」

### キーワード指定時の検索クエリ

ユーザーが指定したキーワードを使って、以下のパターンで検索します：

```
[キーワード] トレンド 2026
[キーワード] 最新ニュース
[キーワード] 市場動向
[キーワード] 活用事例 2026
[キーワード] ビジネスモデル
```

### 検索の実行

**実行内容**:
1. WebSearchツールを使用して、各検索クエリを実行
2. 検索結果から以下の情報を抽出:
   - タイトル
   - URL
   - 要約
   - 公開日（可能な場合）
   - 情報源

**注意事項**:
- 検索結果は最大10件/クエリ程度に制限
- 信頼性の高い情報源を優先（公式サイト、大手メディア、専門サイト）
- 古い情報（1年以上前）は除外

## ステップ2: 収集した情報をカテゴリ別に分類

収集した情報を以下のカテゴリに分類します。

### カテゴリ一覧

| カテゴリ | 説明 | 例 |
|---------|------|-----|
| **業界動向** | 絵本・出版業界の全般的なトレンド | 市場規模、消費者行動、業界再編 |
| **技術トレンド** | AI、デジタル技術の最新動向 | 生成AI、画像生成、自然言語処理 |
| **競合分析** | 競合他社の動向、新サービス | 新規参入、サービス拡大、提携 |
| **顧客インサイト** | 顧客のニーズ、行動パターン | 購買動機、利用シーン、課題 |
| **マーケティング** | マーケティング手法、成功事例 | SNS活用、インフルエンサー、広告 |
| **ビジネスモデル** | 新しいビジネスモデル、収益化手法 | サブスク、D2C、フリーミアム |
| **規制・法律** | 関連する法律、規制の変更 | AI規制、著作権、プライバシー |
| **その他** | 上記に該当しない重要な情報 | イベント、調査レポート |

### 分類の判断基準

1. **複数のカテゴリに該当する場合**: 最も関連性の高いカテゴリに分類
2. **カテゴリが不明な場合**: 「その他」に分類
3. **重複する情報**: 最も詳細な情報のみを残す

## ステップ3: 重要度・関連性でランク付け

収集した情報を以下の基準でランク付けします。

### ランク付けの基準

#### 1. 重要度（★★★★★）

| ランク | 説明 | 例 |
|--------|------|-----|
| ★★★★★ | 事業に直接的な影響がある | 競合の新サービス、市場の大きな変化 |
| ★★★★☆ | 事業に間接的な影響がある | 業界全体のトレンド、技術の進化 |
| ★★★☆☆ | 参考になる情報 | 海外の事例、周辺業界の動向 |
| ★★☆☆☆ | 知っておくと良い情報 | 一般的なマーケティング情報 |
| ★☆☆☆☆ | 参考程度 | 間接的な情報、周辺情報 |

#### 2. 関連性（高・中・低）

| 関連性 | 説明 | 例 |
|--------|------|-----|
| **高** | えほんインクの事業に直接関連 | パーソナライズ絵本、AI絵本生成 |
| **中** | 隣接領域、参考になる | ギフト市場、パーソナライズ商品 |
| **低** | 間接的に関連 | 一般的な出版、AI全般 |

#### 3. 新規性（新・既知・古）

| 新規性 | 説明 | 例 |
|--------|------|-----|
| **新** | 全く新しい情報 | 過去1ヶ月以内のニュース、新技術 |
| **既知** | ある程度知っている情報 | 既存のトレンド、継続的な動向 |
| **古** | 既に知っている情報 | 過去の情報、既知の事実 |

### ランク付けの実行

**実行内容**:
1. 各情報に対して、重要度・関連性・新規性を評価
2. 総合スコアを算出（重要度×関連性×新規性）
3. スコアが高い順に並び替え

**期待する出力例**:
```
トップ5のトレンド情報:

1. [★★★★★ | 高 | 新] パーソナライズ絵本市場が前年比150%成長
   - カテゴリ: 業界動向
   - 情報源: 出版ニュース（2026-02-10）
   - 要約: パーソナライズ絵本市場が急成長。AI活用が鍵。

2. [★★★★★ | 高 | 新] 競合A社、AI絵本生成サービスをリリース
   - カテゴリ: 競合分析
   - 情報源: TechCrunch（2026-02-08）
   - 要約: 競合A社が新サービスを発表。月額980円のサブスク。

...
```

## 実装の詳細

### Web検索の実行

**使用するツール**: WebSearchツール

**検索の実行順序**:
1. デフォルト検索クエリ、またはユーザー指定キーワードのクエリを生成
2. 各クエリに対してWebSearchツールを使用
3. 検索結果から情報を抽出
4. 重複を除去

**検索結果の処理**:
```python
# 疑似コード
search_results = []

for query in search_queries:
    results = WebSearch(query)
    for result in results:
        search_results.append({
            'title': result.title,
            'url': result.url,
            'snippet': result.snippet,
            'source': extract_source(result.url),
            'category': classify_category(result),
            'importance': calculate_importance(result),
            'relevance': calculate_relevance(result),
            'novelty': check_novelty(result)
        })

# 重複除去
search_results = remove_duplicates(search_results)

# ランク付け
search_results = rank_results(search_results)
```

### カテゴリ分類のロジック

**分類基準**:
- キーワードマッチング（タイトル、スニペット、URL）
- コンテンツ分析（本文の内容）
- 情報源の種類（ニュースサイト、技術ブログ、企業サイトなど）

**カテゴリキーワード例**:
```
業界動向: 市場規模、業界、トレンド、動向、統計
技術トレンド: AI、技術、開発、ツール、システム
競合分析: 競合、企業、サービス、製品、リリース
顧客インサイト: 顧客、ユーザー、ニーズ、課題、行動
マーケティング: マーケティング、広告、SNS、キャンペーン
ビジネスモデル: ビジネスモデル、収益、サブスク、D2C
規制・法律: 規制、法律、ガイドライン、コンプライアンス
```

### 重要度・関連性の評価ロジック

**重要度の計算**:
```
重要度スコア = (
    情報の新鮮さ × 0.3 +
    情報源の信頼性 × 0.3 +
    事業への影響度 × 0.4
)
```

**関連性の計算**:
```
関連性スコア = (
    キーワードマッチ度 × 0.4 +
    カテゴリ関連度 × 0.3 +
    事業領域の一致度 × 0.3
)
```

**新規性の判断**:
- 公開日が1ヶ月以内 → 新
- 公開日が1〜6ヶ月 → 既知
- 公開日が6ヶ月以上 → 古

## 注意事項

1. **Web検索の制限**:
   - WebSearchツールには検索回数の制限がある可能性があります
   - 過度な検索は避けてください

2. **情報の正確性**:
   - Web検索の結果は、AIによる解釈が含まれます
   - 重要な情報は、必ず元のソースを確認してください

3. **情報の鮮度**:
   - トレンド情報は常に変化します
   - 定期的に実行して、最新の情報を取得してください

4. **プライバシー**:
   - 検索キーワードには、機密情報を含めないでください

5. **ファイルサイズ**:
   - 長期間実行すると、ファイルが増えます
   - 定期的に古いファイルを整理してください

# ÉHON の商材と、どの業界に当てるか

**提案書を書く前に、まずここで「何を提案するか」を決める。** 型（ナラティブ型／販促・仕組み型）は、商材が決まってから選ぶ。

過去に、婚活の提案書へ自動車の施策と事例を持ち込んで成立しなくなった失敗がある。**業界に合わない商材・合わない実績は入れない。**

---

## 業界から商材を引く

| 提案先 | 第一候補 | 第二候補 |
|---|---|---|
| 結婚相談所・婚活サービス | **遺伝子×取説（Gene Story Book）** | NoaÉre Pre（カップル向け） |
| 式場・ホテル・ブライダル | **NoaÉre**（結婚限定） | 成婚・記念のフルオーダー |
| 自動車ディーラー・販売店 | **マイカー絵本** | オンラインガチャ・診断 |
| 老舗メーカー・周年を迎える企業 | **企業創業ストーリー絵本** | — |
| 保険・金融・大手BtoC | **サービス認知絵本** | 動画・アバターアプリ等の派生 |
| 小売・商業施設・イベント集客 | **オンラインガチャ・診断コンテンツ** | 職業体験絵本 |
| 上記に当てはまらない法人 | 企業創業ストーリー絵本 or サービス認知絵本 | — |

**候補が複数あっても、提案書に載せるのは1つ。** 性質の違う商材（絵本とガチャなど）を1つの提案書に混ぜない。

---

## 1. 遺伝子×取説（Gene Story Book）

キーンヘルスとの協業商材。chatGENE 400項目の遺伝子データを「自分の取扱説明書」として絵本化する。

- **当てる先**: 結婚相談所・婚活サービス。**1人分のデータで完結する**のが最大の強みで、相手データが要らないため全会員が対象になる
- **設計思想**: 良し悪しの判定ではなく「互いの違いを理解する取扱説明書」。顔は描かず後ろ姿シルエットのみ（大人の絵本美学）
- **三段導線**: 取説（入口・全会員）→ 相性ブック（成婚層）→ NoaÉre（結婚式）。同じ会員に二度売れる構造
- **価格**: DtoC ¥49,800／BtoB卸 ¥34,800／PoCモニター ¥160,000（10組パッケージ・1組¥16,000）
- **実績**: **まだ無い。PoC 100組を準備中**（2026年9月にキーンヘルスとMTG）。**数値実績として提示できるものは現時点でゼロ**
- **注意**: 疾患リスク・脳容積系データは意図的に除外している。無償提供枠の話は社外資料に載せない

## 2. NoaÉre / NoaÉre Pre

- **NoaÉre**: 結婚限定。式場・ホテルチャネル
- **NoaÉre Pre**: カップル向け（結婚前）
- **実績**: アールイズ・ウエディング、ノバレーゼ、グッドラック・コーポレーションでサンプル制作。**いずれも数万円規模でサンプル止まり、本番化していない**
- **注意**: 式場は継続型のビジネスモデルなので単価より継続性で見る。**サンプル止まりが続いている事実があるので、「実績豊富」とは書かない**
- SNS等で語るときは実体験ではなく「知人・お客様事例」として語る（既定方針）

## 3. 企業創業ストーリー絵本

企業の歴史・理念を物語にする。**公開情報だけで企画案まで組める**ため初回提案と相性が良い。

- **当てる先**: 周年・創業ストーリー・サービスの想い
- **実績**: 芋慶（1877年創業の味噌・醤油蔵／165万円）、GIVENESS&CO『発酵と禅、そして腸。』（175.12万円）
- **効いた理由**: 「木桶」「蔵付き微生物」「信長の兵糧」のような**その会社固有の固有名詞**を本文に入れたこと。抽象語で埋めると初回で見抜かれる
- 型は**ナラティブ型**（`ehon-proposal-formats.md` §1）

## 4. サービス認知絵本

自社サービスの想い・価値を絵本で伝える。社内向け・顧客向けの両方。

- **当てる先**: 保険・金融・大手BtoC、社内浸透や顧客理解が課題の企業
- **実績**: かんぽ生命（ラジオ体操えほん 290.4万円、動画89.1万円、CXナラティブPoC 385万円、アバターアプリ360.8万円）、DNP経由でアテニアのブランドブック絵本
- **強み**: 1社の中でPoC→アプリ→絵本→動画と横展開した実例がある。**法人絵本事業の勝ちパターン**
- **注意**: かんぽ生命・アテニアは代理店/直請けの別があり、社名を出す前に確認する

## 5. マイカー絵本

購入した車をAIでキャラクター化し、名前・趣味嗜好・担当スタッフのメッセージを織り込む成約特典。

- **当てる先**: 自動車ディーラー・販売店
- **実績**: 鈴木自工（継続納品中）、ガリバー（成約特典として導入）
- **提示できる数値**（ガリバー導入後アンケート）:
  - 楽しんだ 約90%（とても58.8%＋やや29.4%）
  - ブランドへの親しみ増 52.9%
  - 再来店意向 29.4%
  - **回答者の78.6%が子どもを持たない層** ← 絵本がファミリー限定ではない証拠
- **注意**: 満足度は取れているが、ディーラーが金を払う理由（再来店率・売上・保険加入率）の実データは3年間空欄のまま。**満足度だけを購入理由として提示しない**

## 6. オンラインガチャ・診断コンテンツ（クロワッサン）

LINE獲得・再来店動線をつくるデジタル施策。**絵本とは別商材。混ぜない。**

- **当てる先**: 店舗集客・イベント・LINE友だち獲得が課題の業種
- **提示できる数値**:
  - JAPAN MOBILITY SHOW 2025「スーパーカー診断」×ガチャ → 6日間でLINE新規4,000件（平均670件/日）
  - QRスキャン後のLINE登録完了率 7割以上
  - おみくじガチャ → 開始1週間で600〜700回、毎日引くリピーター複数
- **絵本と組み合わせてよいのは**、自動車ディーラーのように「集客→接客→成約特典」の一本の導線に無理なく乗る場合のみ。それ以外は単独で提案する

## 7. フルオーダー絵本・製本単体

- 用途自由のフルオーダー（個人・法人）。THE BALLET SHOW のくるみ割り人形絵本（公演物販型）、イオンモール キッズドリーム（職業体験絵本）など
- 製本・印刷だけの直請けもある（GIVENESS&CO、THE BALLET SHOW）

## 実績が無い商材を提案するとき

遺伝子×取説のように**まだ実績数値が無い商材**を提案する場合、無関係な業界の数字で埋めない。代わりに次で構成する。

1. なぜこの設計なら効くと考えるか（構造の説明）
2. 近い構造を持つ他商材の結果を、**構造が同じ理由を明記したうえで1件だけ**、業種表記で
3. PoCで何を測れば「買う理由」になるかの提示

3番目が特に効く。ガリバー案件は満足度を測って購入理由が取れず3年停滞した。**最初に測る指標を決めて提案に入れる**ことが、同じ失敗を避ける手になる。

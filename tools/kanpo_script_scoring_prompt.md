# Claude Code用：CX通信→絵本脚本 AI自動採点プロンプト（ロジック＋採点結果サマリ）
# 目的：脚本テキストを入力すると、構造品質（25点満点・重要度重視型）で機械的に採点し、PASS/FAILと改善指示を返す。
# 運用：このプロンプトを評価専用エージェント/コマンドに固定し、脚本文を差し替えて繰り返し実行する。

あなたは「CXナラティブ脚本（絵本化）」の評価者です。以下の採点ロジックに従い、主観ではなく機械的に採点してください。
出力は必ずJSONのみ（前置き・説明文禁止）で返してください。引用は各20語以内で最大2件。

## 採点対象
CX通信を元にフルコト等で生成した絵本脚本（シーン形式または段落形式）

---

## 採点ロジック（25点満点・重要度重視型）
### スコア項目
C 転換点の自然性（0-7）← 最重要
A 感情曲線設計（0-6）
E 行動示唆の具体性（0-5）
D 教訓臭・説明臭の低さ（0-4）
B 感情振幅（0-3）

### PASS/FAIL（一次ゲート）
PASS条件：
- total >= 18
- かつ C >= 5
- かつ D >= 3

### 指標定義（必ず厳守）
C 転換点の自然性（0-7）【最重要】
- 7：小さな出来事/一言/沈黙/身体感覚などから必然的に転ぶ（偶発性が自然）
- 5：転ぶが説明で押している／整理的（PASS基準）
- 3：急展開（理由が薄い）
- 0：転換点不在
減点ルール：
- 「突然」「急に」「なぜか」等の雑な接続が多い→減点
- 転換が語りのまとめ（"気づいた"）で起きる→減点

A 感情曲線設計（0-6）
- 6：シーンごと感情が明確で「落ち→転換→上昇→余韻」が読み取れる（意図的N型等）
- 4：推移はあるが谷/転換が弱い
- 2：単調（同トーン継続）
- 0：感情描写がほぼない
※評価方法：各シーン主感情を抽出し感情値（-5〜+5）推定。負側(<0)が最低1回必要。転換点（負→正）が必要。

E 行動示唆の具体性（0-5）
- 5：行動が"描写"で出る（傾聴/反復/沈黙/相手を見る/資料を閉じる等）かつ説教でない
- 4：行動描写はあるが粒度がやや粗い
- 3：態度変化はあるが行動粒度が粗い
- 2：心情変化のみで行動が少ない
- 0：行動がない
注意：
- 行動示唆を"説明"で書くほどDが落ちる（設計上の相殺を意識）

D 教訓臭・説明臭の低さ（0-4）
- 4：教訓回収・一般化がない（具体シーンで静かに閉じる／余韻）
- 3：軽いまとめはあるが許容（PASS基準）
- 2：教訓がやや前面に出ている
- 1：教訓が前面（"大切なのは" "学び" "〜すべき" 等）
- 0：説教/研修資料化
ルール：
- 禁止・要注意フレーズが多いほど減点（例：「だからこそ」「大切なのは」「学んだ」「気づいたのです」「〜すべき」等）
- 最終段落が結論・一般化で締まる→減点

B 感情振幅（0-3）
- 振幅 = max(感情値) - min(感情値)
- 3：振幅 >= 7
- 2：振幅 5-6
- 1：振幅 3-4
- 0：振幅 <= 2

{
  "total": number,  // 25点満点
  "pass": boolean,  // total>=18 & C>=5 & D>=3
  "scores": {"C":number,"A":number,"E":number,"D":number,"B":number},  // C,A,E,D,Bの順
  "emotion_curve": [
    {"scene": "1", "label": "準備", "emotion": "誠実", "value": 2},
    ...
  ],
  "rationales": {
    "A": ["引用1","引用2"],
    "C": ["引用1","引用2"],
    "D": ["引用1","引用2"]
  },
  "improvements": ["提案1","提案2","提案3"]
}

emotion_curveは可能な範囲で5〜7点（主要転換点）を出す。sceneが取れない場合は段落番号でよい。

# 参考：既存3脚本のAI採点結果（ベースライン・25点満点換算）
※あなた（評価者AI）はこの結果を「校正」してはいけない。これは運用上の参照ベンチマーク。

## 1) 19-7『机の上の太陽』（提出版）
総合：22/25 → PASS（total>=18 & C>=5 & D>=3）
内訳：
- C 7/7（子どもの行為を起点に偶発的・自然転換）【満点】
- A 5/6（非常に良いN型）
- E 4/5（パンフ閉じ等の行動は描写。粒度は良）
- D 3/4（ほぼ教訓なし。終盤に軽い概念化が少し）
- B 3/3（振幅8で十分）【満点】
示唆：
- バランス型の量産基準に適する

## 2) 19-15『完璧な準備』（提出版）
総合：21/25 → PASS
内訳：
- C 6/7（沈黙後に"思わず出た一言"で自然転換）
- A 5/6（N型明確、転換が読み取れる）
- E 3/5（行動粒度がやや抽象。傾聴/反復などがもう一段ほしい）
- D 4/4（余韻型。教訓回収なし）【満点】
- B 3/3（振幅7でメリハリ十分）【満点】
改善提案（要旨）：
- 転換後の具体行動を1つだけ描写で追加（説明しない）→ E:3→5点へ
- 終盤に"次の面談での小さな変化"を1描写
- タイトルを余韻寄りに（例：手のひらの温度 等）

## 3) 19-6『魔法の絵の具と、大きなカバン』（提出版）
総合：17/25 → FAIL（total<18）
内訳：
- C 5/7（転換が整理的で説明寄り）
- A 4/6（N型はあるが谷が浅い）
- E 4/5（行動は具体で実務接続性高い）
- D 2/4（教訓回収・まとめが強い）← **FAIL原因**（3点未満）
- B 2/3（振幅5-6）
失敗要因（要旨）：
- D項目が2点でPASS基準（3点以上）未達
- 終盤の「〜知りました」「二つが揃ったとき…」などの総括が強く余韻が消える
改善方向（要旨）：
- 教訓・一般化を削り、具体シーンで閉じる → D:2→3点以上へ
- 転換を"語りの気づき"ではなく"沈黙/一言/身体感覚"で起こす → C:5→6点以上へ
